## G: gaps in the sources, with the repair formalized

**G1 (translating Wei and Ghosal 2020, Theorem 3.3, to the thesis).** Not a gap in their paper: there the threshold is chosen ("some a_n < ε̄_n/p"), and their proof of (3), display (20), bounds the Gaussian part by a term of the form exp(−a_n² p^{−2(1+μ'')}/α²)/(a_n p^{−(1+μ'')}/α), which is small only if a_n p^{−(1+μ'')}/α → ∞, i.e. only if the threshold a_n is not too small relative to α. In the thesis the threshold δ_n is a given sequence, so this requirement must become a hypothesis; their own hypothesis −log α = O(log p) becomes log(1/τ_n) ≤ B log J_n. Repair, formalized in `HorseshoeAssumption3Statement`: the threshold satisfies δ_n ≥ c_δ ε̃_n/J_n for a constant c_δ > 0 (the thesis's Corollary 1 uses δ_n = c_δ ε̃_n/J_n, so it is covered), and log(1/τ_n) ≤ B log J_n. The author's statement "the paper can be translated verbatim" holds with these two hypotheses made explicit. The repair is sufficient, not minimal (any δ_n ≥ (4/π)√(2Λ_n) J_n^{−(1+μ''/2)}/√n works); it is the natural one for the thesis. The hypotheses together force c_δ ≤ 1 and B > 2 + μ'' (Gate B). Two budget hypotheses are quantitative forms of Wei–Ghosal's ε̄_n ≻ √(s log p/n): a_n log J_n ≤ B n ε̃_n² (weaker than theirs) and log(1/ε̃_n) ≤ B log J_n (an addition with no counterpart in their Theorem 3.3; Gate B showed it is redundant: it follows eventually from the τ_n bound, log(1/τ_n) ≤ B log J_n, and n ε̃_n² → ∞, so it costs nothing).

**G2 (pointwise infimum in (WG5) and the horseshoe).** The horseshoe density is +∞ at 0, so any real-valued version must assign some value there; Lean's version (D4) stores 0, which would make a pointwise infimum over [−E, E] equal to 0. The formalized (WG5) asks for a lower bound almost everywhere on [−E, E] (D2), which is implied by the paper's form and is version-free.

## D: modelling decisions (each with rejected alternatives)

- **D1. (WG4) as a lower bound on the probability**, Π(...) ≥ exp(−c₄ n ε̃²), equivalent to −log Π(...) ≤ c₄ n ε̃². Rejected: the log form (needs a separate positivity hypothesis because log 0 = 0 in Lean).
- **D2. (WG5) with an a.e. lower bound π_low > 0 on [−E, E].** Implied by the paper's form (take π_low = inf), so Theorem 1 under D2 implies Theorem 1 as stated. Rejected: `sInf` over the image of a fixed version (version-dependent; fails for the horseshoe at 0, see G2).
- **D3. Assumption 2 and (WG4) bundled:** "for all large n there exist θ₀, S with Assumption 2 and (WG4) for S". This is the paper's "fix one approximant and its ξ*_n; (WG4) holds for it". The horseshoe theorem proves (WG4) for every S of size a_n. Rejected: (WG4) for all S (stronger hypothesis than the paper's).
- **D4. Horseshoe density at t = 0.** Defined as the Bochner integral, which Lean sets to 0 where the integrand is not integrable (only t = 0). The measure is unchanged (one point is Lebesgue-null). Rejected: a lintegral-then-toReal definition (same value 0 at t = 0, more awkward); an `if t = 0` patch (arbitrary).
- **D5. Vector form.** Functions are their evaluation vectors at the n design points (as in the paper's notation paragraph); the dictionary is the n × J matrix X; f_θ = Xθ. The design is a triangular array (any points for each n). Rejected: functions on a domain with a design map (adds nothing the theorem uses).
- **D6. Likelihood ratio in closed form and posterior by Bayes' formula** on (Fin J → ℝ). Fidelity is certified by the Lean lemma `dataLaw_eq_withDensity` (P_g = P₀ with density L(g; ·)). Rejected: abstract densities p_θ/p₀ (needs Radon–Nikodym derivatives and versions).
- **D7. Two forms of Theorem 1.** `MasterStatement` at a fixed n with the seven eventual conditions (e1)–(e7) as explicit hypotheses, and `AsymptoticStatement` exactly as in the paper. Rejected: the asymptotic form only (hides the conditions).
- **D8. Lemma statements in generic form** where the proof is the same: Lemma 2 for any prior probability measure and any mass constant c and radius factor L; Lemma 3 for every k; Lemma 4 for any budget m with the two inequalities it needs; Lemma 7 for any budget m. The master proof instantiates them with the paper's constants.
- **D9. Lemma 7 indexed by coefficient vectors** (θ with N_δ(θ) ≤ m in the ℓ-th shell), not by the function sets W_n and S_ℓ. The standalone proof uses only the forward implication θ ∈ Θ_n ∩ U_n ⇒ f_θ ∈ S_ℓ, so nothing is lost.
- **D10. Horseshoe constants.** μ = μ''/2, c₄ = 1, c₅ = B(6 + 5B); hypotheses in the Wei–Ghosal style (τ_n ≤ J_n^{−(2+μ'')}/√n, a log-budget with constant B). Rejected: asymptotic O(·) hypotheses without explicit constants (not formalizable as stated).
- **D11. B-splines.** Cox–de Boor recursion on clamped uniform knots (multiplicity q at 0 and 1), order-one functions closed at x = 1 on the last nondegenerate interval, 0/0 = 0 (Lean's and the standard convention). Rejected: B-splines as an abstract basis with assumed properties (would assume what is to be proved).
- **D12. Fourier atoms** ψ₀ = 1, ψ_{2j−1} = √2 cos(2πjx), ψ_{2j} = √2 sin(2πjx), tensor products; the basis theorems cover every finite family of atoms (so every dictionary built from them, including multiresolution unions and tensor products), at any design (Fourier) or any design in [0,1]^d (B-splines).
- **D13. Eventual hypotheses.** Every hypothesis on the sequences (positivity, 1 ≤ a_n ≤ J_n, δ_n ≤ ε̃_n/J_n, Assumption 1, the densities) is required only for all large n, as in the manuscript (the standalone asks for every n); J_n ≥ 2 eventually follows from J_n → ∞ and is not assumed. Kept from the paper although not needed: η < 1, E_n > 0.
- **D14. Convergence in P₀-probability** is written out: for every ζ > 0, P₀{Π(· | Y) > ζ} → 0.
- **D15. Expectations of posterior probabilities** are lintegrals in [0, ∞] (posterior probabilities are measures in [0, ∞], so no `toReal`).
- **D17. Non-vacuity instance uses M_n = log(n+2)** (changed from n after Gate B, so that M_n ε_n → 0 and the witnessed conclusion concerns shrinking balls). Only the body of the example definition `nvM` changed; no statement type changed; refrozen as v2.
- **D16. Scope.** Assumption 2 for Hölder f₀ (Appendix D: Jackson inequality, Schumaker's spline approximation) and Corollary 1 are not formalized; Theorem 1 takes Assumption 2 as a hypothesis, as in the paper.
